# Pass 40.2 — Test-suite quality scaffolding

Date: 2026-05-12
Status: shipped

## Motivation

Audit G (Pass 40, ADR-0230) returned 38 useless-test findings
dominated by silent-success fakes, trivially-true lipgloss
assertions, `t.Skip` placeholders, and `cmd != nil` shape
assertions. Coverage was high; observation was nil. Pass 40.1
fixes the 21 P1 instances by hand; this pass installs the
mechanical answer so the regression class can't re-enter.

## Scope (this pass — scaffolding only)

1. `scripts/check-deep.sh` — gremlins runner across a curated
   list of pure-logic packages (`mailcompose`, `mail`, `cache`,
   `content`, `filter`, `tidytext`, `mailauth`, `config`). UI,
   network backends, and terminal probing excluded with reasons.
   Per-package efficacy threshold; initial 0% (informational)
   pending calibration after 40.1.
2. `make check-deep` target — pass-end gate, not in `make check`.
3. ADR-0232 — decision record + rationale.
4. `go-conventions` skill — new "Assertion Discipline (no
   useless tests)" subsection codifying the five Audit G
   anti-patterns: silent-success fakes, self-derived
   expectations, trivially-true style assertions, `cmd != nil`
   without invoke, unconditional `t.Skip`.
5. `invariants.md` + `decisions/INDEX.md` — pointer rows.
6. BACKLOG #59 — AST-based unconditional-`t.Skip` detector
   queued for follow-up pass (small `go/parser` + `go/ast`
   walker; complements `check-deep` at the fast-feedback end).

## Out of scope (queued for Pass 40.3, post-40.1)

- Calibration run: gremlins on all 8 curated packages against
  the post-40.1 suite; set per-package efficacy thresholds
  from observed scores. Target ≥80% for `mail`, `cache`,
  `mailcompose`; lower for less critical packages.
- BACKLOG #59 implementation: small Go tool (~50 LOC),
  `scripts/skipcheck/main.go` or similar, wired into `make
  check` alongside `voice-check` and `modern-go-check`.

Calibration deliberately runs *after* 40.1 because mutation
scores against a suite still carrying silent-success fakes are
noise; the meaningful baseline is the post-remediation suite.

## Smoke test

`gremlins unleash -t dev ./internal/mailcompose` (2026-05-12):
65 killed, 14 lived, 11 not covered, 46 timed out → 82.28%
efficacy, 87.78% mutant coverage in 19s. The 14 survivors are
genuine test-quality findings to revisit during calibration.

## Decision record

ADR-0232 carries the full decision. Index row updated.

## Why a sibling pass to 40.1, not folded in

Pass-size budget (CLAUDE.md: 8–12 tasks, one ADR per pass). 40.1
is mechanical remediation of 21 P1 fakes; 40.2 introduces a new
gate + skill section. Different shapes; merging them blurs the
review focus. Pre-beta endorses both running back-to-back.
