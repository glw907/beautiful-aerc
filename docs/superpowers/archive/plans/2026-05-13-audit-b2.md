# Audit B.2 — general structural integrity

Date: 2026-05-13
Pass: 31
Audit phase: B.2 (`docs/poplar/audit-plan.md` §"Phase B.2")
Trigger: Audit B.1 returned a clean Elm/v2 surface (ADR-0215).

The audit walks four focuses: `app.go` decomposition regression,
file-size budget, interface count after `Editor` deletion, and
package-boundary leaks. Findings are classified P0 (apply inline
this pass), P1 (BACKLOG / ROADMAP), or P2 (note in this ADR
only).

## 1. `app.go` decomposition regression

### Dispatch chain (`App.Update`)

`tea.WindowSizeMsg` and `tea.KeyPressMsg` route to dedicated
handlers; every other `tea.Msg` walks the chrome → outbox →
compose → modals → contacts chain and falls through to
`acct.Update` as the default. The chain is exhaustive: each
dispatcher returns `(App, tea.Cmd, bool)` and the third value
gates fall-through. No back-channel call from one
`update<Domain>Msg` into another — domain helpers (`armToast`,
`maybeResizeChild`, `dispatchUnsubscribe`, `confirmYes/No/Closed`)
are private to their file and reached only from within it.

**Finding A (P0).** `App.updateKey` is 175 lines and splits
naturally on the overlay-cascade / global-shortcut seam: lines
16–86 route into whichever overlay is open, lines 87–188
dispatch top-level shortcuts (Compose, Reply, Undo, Quit,
ForceQuit, OutboxOverlay, ConflictOverlay, Help, SenderPopover,
ContactsMode) and fall through to `acct.Update`. Extract
`routeOverlayKey(msg) (App, tea.Cmd, bool)` and
`updateGlobalKey(msg) (App, tea.Cmd)`; `updateKey` becomes the
thin top-level chain. No behavior change.

## 2. File-size budget

Non-test files in `internal/ui/` exceeding ~600 lines:

| File                                 | Lines | Reason |
|--------------------------------------|------:|--------|
| `internal/ui/messagelist/model.go`   | 1111 | `Model` owns threading, fold state, group→sort→flatten pipeline, embedded `bubbles/v2/list.Model` + custom `*rowDelegate`. ADRs 0198, 0199. |
| `internal/ui/compose/model.go`       | 1066 | Single inline-compose `Model`: five focusable fields, embedded `catkin.Model` (ADR-0213), Dropdown autocomplete, Attach/Schedule pickers, Tidy seam, identity + signature picker, autosave + dirty tracking. |
| `internal/ui/contacts/form.go`       |  991 | Edit-form sub-model: VCard field model, multi-row list editors (emails / phones / urls / orgs), focus walk, validation, draft buffer. |
| `internal/ui/account/model.go`       |  873 | Account screen `Model`: composes `sidebar.Column`, `messagelist.Model`, `reader.Model`, owns triage dispatch + cache reads + folder navigation. |
| `internal/ui/cmds.go`                |  685 | App-side `tea.Cmd` library: every fallible I/O leaves through here (compose seed, draft load, outbox ops, retention sweep, empty-folder fan-out, link/attachment open). |
| `internal/ui/sidebar/model.go`       |  643 | Sidebar `Model`: three folder groups, tree expansion (ADR-0198), per-session fold state, layout-tier-driven width math. |

Every overflow is a `Model` (or, for `cmds.go`, the App-side Cmd
surface) whose state genuinely justifies the surface — the
audit-plan's stated escape hatch. **P2 — note only.** The
ongoing `ui-all-value` ROADMAP project (filed by Audit B.1) will
naturally re-touch these files; if any of them stays this large
after the all-value conversion and still feels like more than one
responsibility, that's a future audit's call to make. The
audit-plan does not call for proactive splits; it calls for
names, and the names are here.

## 4. Package-boundary leaks

`grep -rn "glw907/poplar/internal/ui\"" internal/ui/{account,
compose,helppopover,messagelist,movepicker,reader,sidebar,
wizard,contacts,uicore}` returns zero hits. No subpackage
imports the parent. The cross-boundary Msg vocabulary lives in
`<subpkg>/msgs.go` and is qualified at the App-side call site
(`account.TriageStartedMsg`, `compose.SendMsg`,
`contacts.OpenPopoverMsg`, etc.). **Clean.**

## Approach

1. Split `App.updateKey`: extract `routeOverlayKey` (lines 16–86
   verbatim, with the early-return guards converted to
   `(App, tea.Cmd, true)`) and `updateGlobalKey` (lines 87–188).
   `updateKey` keeps `NotifyActivity` + the contacts-mode
   short-circuit and chains the two helpers.
2. Pass-end ritual (`poplar-pass`): ADR-0216, invariants
   touch-up (none expected — the structural facts already match
   what's in invariants.md), STATUS update, plan archival,
   `make check`, commit + push + install.
