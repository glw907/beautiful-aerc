**Goal.** Replace the 14b OAuth strategy stub (`echo
TODO-pass-14.1-oauth`) with a real loopback-PKCE consent flow,
refresh-token persistence (keyring + age-file fallback), and
proactive access-token refresh so Gmail and Outlook accounts
finish the wizard end-to-end and survive token rotation.

**Architecture.** Three layers: `internal/mailauth/oauth.go`
(Client + Authorize + Token wrapping `golang.org/x/oauth2`),
`internal/mailauth/tokenstore.go` (TokenStore interface +
KeyringStore + AgeFileStore + OpenStore probe), and
`internal/wizard/oauth_strategy.go` (`oauthStrategy` impl + huh
sub-screen). Backend integration threads a `*mailauth.Client`
into `mailimap.Backend` and routes Token() into the existing
XOAUTH2 path. `--reauth=<name>` mirrors `--repair=<name>`.

**Tech stack.** `golang.org/x/oauth2`, `zalando/go-keyring`,
`filippo.io/age` (already in tree via poplar's general tooling
posture; add to go.mod if absent), stdlib `net/http` for the
loopback callback server.

// Implementations: KeyringStore (system keyring via zalando/go-keyring) and

```go
type Config struct {
    ClientID, ClientSecret string
    AuthURL, TokenURL      string
    Scopes                 []string
    RedirectPortRange      [2]int
}

type Client struct {
    cfg   Config
    store TokenStore
    slug  string

    mu        sync.Mutex
    cachedTok string
    expires   time.Time
}

func NewClient(cfg Config, store TokenStore, slug string) *Client

func (c *Client) Token(ctx context.Context) (string, error) {
    c.mu.Lock(); defer c.mu.Unlock()
    if c.cachedTok != "" && time.Until(c.expires) > 5*time.Minute {
        return c.cachedTok, nil
    }
    refresh, err := c.store.Get(c.slug)
    if err != nil || refresh == "" {
        return "", fmt.Errorf("oauth refresh missing: %w", mail.ErrAuth)
    }
    src := c.oauth2Config().TokenSource(ctx, &oauth2.Token{RefreshToken: refresh})
    tok, err := src.Token()
    if err != nil {
        return "", fmt.Errorf("oauth refresh: %w", classifyOAuthErr(err))
    }
    c.cachedTok = tok.AccessToken
    c.expires = tok.Expiry
    // Rotate refresh token if upstream issued a new one.
    if tok.RefreshToken != "" && tok.RefreshToken != refresh {
        _ = c.store.Set(c.slug, tok.RefreshToken)
    }
    return c.cachedTok, nil
}
```

`classifyOAuthErr` maps `*oauth2.RetrieveError` with HTTP 400/401
and body containing `invalid_grant` / `invalid_token` to
`mail.ErrAuth`; anything else passes through.

Picks a free port in the inclusive range (range `{0,0}` →

on `/callback` reads `code` + `state` + `error` query params,

result on `done`, shuts itself down.

In `oauth.go`:

```go
func (c *Client) Authorize(ctx context.Context) error {
    verifier := generatePKCEVerifier()  // 64 random bytes, base64url
    state := generateState()             // 32 random bytes, base64url
    srv, redirect, done, err := runConsentServer(ctx, c.cfg.RedirectPortRange, c.consentTimeout)
    if err != nil { return err }
    defer srv.Shutdown(context.Background())

    authURL := c.buildAuthURL(state, codeChallengeS256(verifier), redirect)
    if err := c.openBrowser(authURL); err != nil { return fmt.Errorf("open browser: %w", err) }

    select {
    case res := <-done:
        if res.err != nil { return res.err }
        if res.state != state { return ErrStateMismatch }
        tok, err := c.exchangeCode(ctx, res.code, verifier, redirect)
        if err != nil { return err }
        return c.store.Set(c.slug, tok.RefreshToken)
    case <-time.After(c.consentTimeout):
        return ErrConsentTimeout
    case <-ctx.Done():
        return ctx.Err()
    }
}
```

`openBrowser` defaults to `xdg-open` / `open` / `cmd /c start`
(per GOOS); test-injectable via unexported `c.openBrowser`
function field + `SetOpenBrowser(c, fn)` test helper. Same shape
for `c.consentTimeout` (default `2 * time.Minute`) +
`SetConsentTimeout` helper.

`generatePKCEVerifier` / `codeChallengeS256` per RFC 7636 §4.1.

```markdown
---
title: OAuth refresh for Gmail/Outlook IMAP
status: accepted
date: 2026-05-10
---

## Context
Pass 14b shipped `StrategyOAuth` as a wizard option but wrote a
placeholder `password-cmd = "echo TODO-pass-14.1-oauth"` because
the real consent flow was out of scope. Gmail and Outlook can't
authenticate IMAP/SMTP without a working XOAUTH2 token path; the
two presets sit unusable until that ships.

## Decision
- BYO OAuth client: user registers their own client in Google
  Cloud / Azure Portal once and pastes client_id + client_secret
  into the wizard. Maintainer-verified clients are out of scope
  (Google CASA audit, Microsoft publisher verification).
- Consent flow is loopback PKCE — universally supported by Google
  and Microsoft, no display-name verification, no device-code
  fallback in v1.
- Refresh tokens persist via `zalando/go-keyring` with a per-
  account age-encrypted file at
  `$XDG_CONFIG_HOME/poplar/oauth/<slug>.age` as fallback. The
  wizard probes the keyring once and records the chosen backend
  in `[account] oauth-store = "keyring"|"age-file"`.
- Access tokens cache in-memory on the `*mailauth.Client`; refresh
  triggers when <5min remains or upstream returns invalid_grant.
- CLI surface: `--reauth=<name>` re-runs the OAuth sub-screen
  against a named account.

## Consequences
Unlocks Gmail + Outlook end-to-end through the wizard.
`password-cmd` stays the parallel auth path for self-hosted IMAP
and Fastmail JMAP — no cross-cutting refactor.
Adds three deps: `golang.org/x/oauth2`, `github.com/zalando/go-keyring`,
`filippo.io/age`. Forecloses device-code in v1; revisit only if
SSH-without-tunneling feedback identifies a real cohort. JMAP
OAuth deferred — Fastmail uses long-lived API tokens; no current
consumer wants it.
```
