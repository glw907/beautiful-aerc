# Human-voice audit — Phase 2 triage

Frozen at end of Pass 8.8 Phase 2. Phase 3 reads from this file.

## Decision rules

For each finding:
- **apply 3a (Pass 8.8)** — string-only fix; comment / error-string edit; reviewer-friendly diff.
- **apply 3b (Pass 8.9)** — structural fix; rename / file-move / interface-shape change; carries `make check` and tmux-render risk.
- **keep** — finding is real but the surface pattern is justified (real seam, real boundary, load-bearing test). One-line reason.
- **taste-call** — reasonable people disagree. Decided here; no taste-calls during Phase 3.

Skip-rationale guard rejects defers framed as "cross-package",
"non-trivial refactor", "churn cost", "out of scope". Pre-beta posture
endorses all of those. The only valid keeps are real-seam, real-boundary,
or load-bearing-invariant.

## Routing summary

Routing rule from the plan: C1 / C7 / C4-prose → 3a. C2 / C5 / C6 / C8 /
C4-structural → 3b.

C4 splits along the prose-vs-structure line. A C4 finding is **prose**
when the fix is "trim or rephrase a comment" — diff is text-only inside
existing godoc blocks. It is **structural** when the fix is "remove the
chorus by deleting most of the docs" or "split the bank or file
differently" — touches symbol shapes, not just strings.
