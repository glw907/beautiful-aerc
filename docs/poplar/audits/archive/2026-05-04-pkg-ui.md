## C8 — Structural symmetry

### internal/ui/ file layout — C8 (T19)

```
cmds.go            — all Cmd builders + their Msg types (617 lines)
toast.go           — toast types + rendering + pendingAction (125 lines)
error_banner.go    — banner rendering (54 lines, one function + helper)
overlay.go         — PlaceOverlay vendor
dim.go             — DimANSI helper (~50 lines)
iconwidth.go       — SPUA cell-width measurement (~50 lines)
top_line.go        — top chrome rendering
```

The Cmd-per-file split (everything in `cmds.go`) coexists with Cmd-related code scattered across `toast.go`. `error_banner.go`, `dim.go`, `iconwidth.go` each contain a single helper purpose. The structure reads as "each concern got its own file at creation time" rather than splitting when a file became unwieldy.

## C2 — Defensive cruft

### account_tab.go:593–596 — C2 (T22)

```go
page := m.pages[folder.Name]
total := 0
if page != nil {
    total = page.total
}
```

`m.pages` is initialized in `NewAccountTab` and entries only ever set by `m.pages[folder.Name] = &folderPage{}`. Selection requires the folder to be loaded, so the nil branch is unreachable.

### account_tab.go:628–630 — C2 (T22)

```go
page, ok := m.pages[name]
if !ok || page == nil || page.total <= 0 || page.loaded >= page.total {
    return ""
}
```

`!ok` already handles absent-key; `page == nil` is redundant defense between package-internal callers.
