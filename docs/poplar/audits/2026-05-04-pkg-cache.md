```
account.go     — Account type + lifecycle
bodies.go      — body cache trio
attachments.go — attachment cache trio
conflicts.go   — RetryOp + DiscardOp + revert helper
drainer.go     — drainLoop + executeOne + dispatch

outbox_reads.go— outbox queries
reads.go       — read queries
schema.go      — migrations
```

`conflicts.go` hosts a sub-topic too thin for a file. `folders.go` is one function; `SyncFolders`/`SyncFolder` are coupled and should sit together. `attachments.go` is a noun-swap clone of `bodies.go` rather than a coupling-driven split.
