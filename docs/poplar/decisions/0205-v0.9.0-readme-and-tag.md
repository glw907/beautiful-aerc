## Context

Pass 20 cuts `v0.9.0`. The repo carried no public-facing README
(the existing file was the obsolete beautiful-aerc landing page
from poplar's predecessor) and the BACKLOG carried three entries
already shipped in Pass 19 — #12 (`internal/tidy` rename), #43
(`MessageInfo.Date` removal), and #44 (`internal/compose` rename).
ADR-0105 fixes the release model; this ADR records what shipped
at tag.

## Decision

- `README.md` is the v0.9.0 GitHub landing page: hero strip with
  the two-pane screenshot, status section near the top, feature
  tour, what's distinctive, wizard-led quickstart with provider
  notes (Fastmail / Gmail / generic IMAP), keybindings table,
  high-level architecture, configuration, contributing, license.
  Tone is polished but restrained — between Charm and aerc norms.
- Hero screenshot lives under `docs/assets/two-pane.png` —
  captured at 1440×900 via `vhs` against the live Fastmail
  account, with the tape file checked in at
  `scripts/screenshots/two-pane.tape`. A compose hero was scoped
  for the same pass but deferred — catkin's live styling and
  JMAP draft sync fought the non-interactive capture; the
  template tape lives at `scripts/screenshots/compose.tape` for
  a hand-driven follow-up.
- License is MIT, already in place. No SPDX header sweep.
- BACKLOG #12, #43, #44 closed with resolution notes pointing
  at Pass 19 / ADR-0203.
- `docs/poplar/system-map.md` and `docs/poplar/v2-roadmap.md`
  swept for Pass 19 renames. Historical ADRs and archived
  plans/specs/audits left as-is.
- Tag `v0.9.0` cut from master. Beta soak begins on tag.

## Consequences

The README unlocks repo-public readiness — an evaluator landing
on the GitHub page now has the feature tour, install path, and
status framing they need.

Tag freezes data formats: cache schema (v12), config layout,
on-disk caches. Post-tag landings on `v0.9.x` are bug-fix only;
features queue on `1.1`. The README's beta-soak promise is the
user-facing contract.

Follow-ups deferred to v1.0 prep (already tracked in BACKLOG):
`CONTRIBUTING.md` (#41), CI workflow with Vale install (#40),
native OAuth (#42), Neovim companion (#6). The compose hero
shot rides into the next post-tag bug-fix window with a
hand-driven capture.
